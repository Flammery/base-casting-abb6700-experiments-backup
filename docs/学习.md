# 2URDF、Xacro、SDF
这三个其实都是机器人模型文件格式。
- URDF:Unified Robot Description Format,ROS最经典的格式
```XML
<link name="link2">

<visual>

<geometry>

<mesh filename="link2.STL"/>

</geometry>

</visual>

</link>
```

- Xacro不是新的格式,它其实就是URDF的模板语言。
Xacro
↓
展开变量
↓
URDF
↓
MATLAB/ROS
- SDF Simulation Description Format,这是Gazebo最喜欢用的格式。URDF只能描述机器人。而SDF还能描述整个世界。因此仿真常用
World

├── Robot

├── Ground

├── Table

├── Camera

├── Light

├── Wind

├── Physics

└── Objects

# 3XML文件
- XML 是一种用标签组织和保存结构化数据的文本文件格式。全称是：XML = Extensible Markup Language， 可扩展标记语言。它看起来像这样：
```xml
<robot name="ur5">
    <link name="base_link"/>
    <joint name="joint1" type="revolute">
        <parent link="base_link"/>
        <child link="link1"/>
    </joint>
</robot>
```
```json
{
  "book": {
    "title": "机器人学导论",
    "author": "John Craig",
    "price": 89
  }
}
```

| XML                 | JSON                |
| ------------------- | ------------------- |
| 使用开始和结束标签           | 使用大括号和键值对           |
| 更适合文档、配置、标准化描述      | 更简洁，常用于软件接口和配置      |
| URDF、Xacro、SDF 使用较多 | Web、Python、软件配置使用较多 |
| 文件通常较长              | 通常更紧凑               |

MATLAB 官方提供机器人轨迹生成以及最小 jerk 轨迹等功能。研究人员通常用它做：
生成平滑关节曲线；
控制速度和加速度；
减少轨迹拐角冲击；
比较不同插补算法；
生成光栅、螺旋、轮廓和平行路径；
为控制器提供参考轨迹。
>路径 Path只描述经过哪里
>轨迹 Trajectory 描述什么时间经过哪里，以及速度、加速度是多少
